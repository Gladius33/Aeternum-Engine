# Reference game packs

- reference-medieval: settlement economy (wood and grain).
- reference-industrial: industrial economy (steel and energy).

Both are data-only API 1 manifests, validated by GamePackLoader and exercised in unit and MariaDB integration CI. See ../schemas/game-pack-v1.schema.json and ../docs/ECONOMY.md. They are engine reference fixtures, not standalone playable games yet. Keep exact manifest bytes and compatible engine code for an existing pinned world.
