## Sources and limits
CNCCFP published 635 formations subject to accounting submission for exercise 2024; the interactive list was updated 5 June 2026. These are financial-regulatory coverage counts, not a full movement census. The published 575-row accounting export is ingested as described below; it is not the entire 635-formation scope. Party Facts 2023 (Bederke, Döring and Regel, DOI 10.7910/DVN/TJINLQ, version 1.1, CC0) has now been collected via a one-shot isolated GitHub Actions workflow from the exact Dataverse release. The 7,199 records across 223 source country codes are pinned (source SHA-256 0f8c594999d784de8c1c2ddc61d18fd6bbe3db6260e5581e31e1942b9dc3c06c). The source codes are not 223 current states: only exact current ISO2/ISO3 mappings enter the 195-country directory; other codes remain available as unmapped academic records, never guessed. All source IDs are retained, independent of the 1,095 electoral observations and 23 curated organizations. Original party-name variants and source years are preserved; absent year is not a verified current status. Manifesto Project 2026a and Global Party Survey are discovery sources, not ingested datasets. The source register keeps their links and classifications. No claim of worldwide exhaustive party, association, union, media, NGO or manifesto coverage; no source rights inferred. Further releases must append verified immutable editions and crosswalks, not overwrite IDs. No change to WP115 files.

## Contract
`PoliticalMovementReference` loads fixed source blobs, validates links, evidence dates and status, computes a SHA-256 edition pin, and exposes country coverage and bounded immutable-edition cursor pages. A client must pin the same edition for all pages. No HTTP route yet: WP123 research API may consume this read model after separate auth and disclosure controls. `php games/world-politics/bin/audit-movement-reference.php [ISO2]` reports coverage and pins offline. Schema is enforced by the typed PHP reader; curated JSON is versioned. Scope and current-identity gaps are explicit. No database migrations or runtime imports.
Tests: `php tests/wp117-movement-reference.php` includes source count, distinct royalist identities, dated roles, document indexes, gaps, pin mismatch, pagination, input tampering and fail-closed runtime admission. Existing source handoff packaging deliberately excludes WP115 staging; the complete documentary registry requires the development repository's pinned input files, and does not activate in the extracted gameplay alpha.
