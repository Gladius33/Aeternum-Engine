# G04 — Illustrated districts

A dedicated district view draws owned holdings from the existing catalogue and progression state, with terrain specific to each pack, original vector architecture, clickable and keyboard-selectable buildings, paged large layouts and mobile adaptation. The positions, scenery and level annexes are illustrative, not simulated coordinates or physical units. No new server mechanics. The player scene uses localized building/resource names and numbered territory/merchant labels rather than opaque IDs. Exact identifiers remain in data attributes and legacy detailed controls; this is not a claim that all legacy screens have been cleaned. Visual capture helper rejects visible long hashes and UUIDs in the scene. Campaigns select buildings in the district and preserve additional desktop/mobile evidence.
