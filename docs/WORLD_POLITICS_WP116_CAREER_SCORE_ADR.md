# WP116 — ADR: identity, offices, mandates, careers and score v2
Status: accepted backend design baseline, executable specification only. Parent: c2bd182c787cdce4bc42d1188f174587fb9659d7. Scope: World Politics branch only. No schema, live API, saved game, score v1 or generic engine changes.

## Decisions and authority
Separate immutable account ID (authentication), person-reference ID (dated documentary identity, nullable for fiction), world-character ID (world-local instantiated actor), career ID (account/world/country), office ID (country/regime/version/function/seat), mandate ID (unique immutable grant), series ID (continuous qualified tenure), control generation (revocable fencing token). Never use real names as keys. Office capacity is one unless a legally defined multi-seat office uses distinct seat IDs. One account has one active career per world initially; compatible secondary offices may belong to the same character only when an explicit jurisdictional compatibility matrix allows them. Unknown compatibility denies. Opposition membership is not an executive mandate. Prime minister, minister, deputy, head of state and head of government are separate functions. An interim office has its own limited authority, not automatic score eligibility.

The future trusted institution adapter certifies appointment/election, legal source, jurisdiction, effective civil day, role, predecessor, mandate expiry and restrictions. The request principal must be resolved from active account/session + world + character + mandate + current generation, never a client-provided role. Each command checks exact office-specific capability, scope and effective day; deny unknown, expired, disputed or stale grants. No privilege from doctrine or affiliation. Research scenarios cannot share gameplay principals. A disputed or extra-constitutional transition may be represented as a noncompetitive aggregate scenario, never an alternative authorization mechanism.

## Future storage and replay contract (WP118–120)
Add new versioned tables, not repurpose v1 rows: career (world, account, country, character, admitted_on, admission cohort); office registry (world, country, regime version, function, seat, powers manifest digest); immutable mandate issuance and closure events (world, career, office, generation, evidence digest, civil date); append-only career event journal (world, career, sequence, event_id, command_digest, previous_digest, payload_digest, committed world revision); active-office unique projection (world, office); active-character/office compatibility projection; idempotency receipts keyed by world, authenticated principal and command ID; score series/checkpoint and ranking snapshot projections with source digests. No physical deletion of historical mandates. Foreign keys include world where applicable; account/person references separate. Store canonical serialization version and hash; replay reconstructs projections and validates evidence references, not merely JSON hashes.

Transitions: admit -> opposition/nonexecutive or certified appointment -> mandate active -> end/revoke -> career persists. Remaniement does not reset career or generate credit. Uninterrupted lawful renewal of the same qualified office retains series; interruption closes series permanently. On loss, freeze series, revoke generation and relinquish office in the same transaction; successor is a new mandate, not transfer of another player's history. World state, debt, population and institutions persist. Lock order: world mutation fence, career/account membership, affected office IDs in sorted order, mandates, projections, receipts; recheck state after locking. Publish only with the existing committed world revision; recovery must rederive pending events and avoid double accrual. Never allow a world clock to advance past uncertified transition. Same command/digest returns receipt; same ID/different digest conflicts. Restore verifies event sequence, scope, generations, dates, active-office uniqueness, credit seal and score recomputation. WP118 must test real MariaDB contention, authorization and rollback; WP119 succession and legal continuity; WP120 atomic publication and tamper detection. No migration execution authorized here.

## Score contract
Use Gregorian civil-date differences in UTC (no elapsed-hour/DST interpretation), half-open intervals [start,end), canonical season start 2027-05-14, common H <= 7305 days, default 7305. T is actual qualified tenure, W is contiguous verified pre-mandate participation from opening admission to first lawful qualifying accession. W is sealed once for a career; a gap makes opening eligibility unverified rather than permitting a fabricated reset. Late takeover is a separate league, W=0; subsequent interrupted series W=0. No score before accession, no reward for nonqualifying accession or research. Preserve account identity and prevent duplicate credit across generations; WP118 must enforce real evidence, WP120 must reject duplicate series/claims. AI absence counts only while verified participation/control remains valid under the cohort's fixed rule; absent before claim or after release never counts. The reference evaluator accepts hypothetical facts for tests only, not proof of these facts.

A(x)=floor(1000*x/365.2425)=intdiv(x*10000000,3652425). Credit points=A(T+W)-A(T), not A(W) separately. Score=max(0,A(T+W)+G). G is real purchasing-power gain in basis points from immutable accession baseline with observations after accession only. No retrospective attribution, no score from pre-mandate growth, nominal currency conversion or artificial population change. Pin comparable population scope, economic model, data and deflator; missing evidence is null, not zero. At accession G=0 only with certified baseline; WP122 must supply verified UC/price methods and comparability. Bound G to existing v1 range [-10000,1000000] and integer arithmetic; never clamp invalid data into a rank. The provisional calculation and qualification status are separate; minimum actual tenure 365 days for both immediate and career starts, a design default, not empirical finding. Research and nonqualifying series always unranked. Experimental eligibility never means official ranking eligibility.

Cohort SHA-256 includes score version, country, opening day, horizon, minimum actual tenure, opening/late/research mode and exact canonical manifest digests: scenario, rules, economy, data, difficulty, participation, autonomy, population scope and mandate authority. No account or world ID in cohort; same opening cohort for direct presidency and qualifying careers. World leaderboard and global leaderboard each select best single eligible series per account per cohort, never sum. Compare score descending then actual tenure descending then gain descending (consistent with v1 precedence); shared rank for complete ties, stable account key for pagination, deterministic best series tie-break by immutable series ID. Use snapshot ID for every page; no cross-cohort/global cross-country composite before qualification. Close historical series immutably; preserve v1 API and cohort archives. V2 read-only versioned endpoints to be introduced in WP120: score report, universe/global cohort discovery, snapshot leaderboard and page; no public score write. Display tenure, credit, gain, provisional state, source evidence and model version separately.
