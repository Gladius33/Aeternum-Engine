# G09 — Ten autonomous opponents per world (lab only)

Thirty distinct bot actors, ten per pinned world. Trusted lab-only policy pinned by checked-in digest, separate from narrower M16 contract. No changes to BotPlan, rules or API permissions. Each tick reads actor-scoped construction, progression, stock, campaign or market, submits at most one ordinary action with a stable per-world/account/tick ID. The real worker completes delayed events. Profiles vary priorities. No direct SQL game-state writes, invented progress, hidden opponent data, LLM or learning. Credentials persist in a private named volume; only the roster is mounted read-only by web. The CI verifies ten bots per world complete at least one actual building and checks human login/construction. This is private lab evidence, not production bot orchestration, competitive benchmark, or release approval.
