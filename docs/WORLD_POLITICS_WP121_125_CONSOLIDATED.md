## Separate research installation (operator-only, not executed)
Use an empty dedicated MariaDB database with a separate account, never the gameplay database. Configure WP_RESEARCH_DB_DSN, WP_RESEARCH_DB_USER, WP_RESEARCH_DB_PASSWORD in the private environment. Runtime account needs SELECT/INSERT/UPDATE on research tables only; installer uses separate DDL credentials.
```sh
WP_RESEARCH_OPERATOR=YES php games/world-politics/research/operator.php install
WP_RESEARCH_OPERATOR=YES php games/world-politics/research/operator.php create-tenant
WP_RESEARCH_OPERATOR=YES php games/world-politics/research/operator.php work
```
Tenant creation outputs a one-time secret; store it privately, do not log it. Rotation takes the tenant ID and revokes earlier keys. Worker consumes at most one job per invocation, rolling back interrupted transactions. Run by bounded operator scheduling. Research webroot is games/world-politics/research/public, with HTTPS, WP_RESEARCH_ENABLED=YES and upstream IP/rate/timeout controls. Do not enable public ingress before independent review. The API does not use gameplay account/session credentials. Use research/openapi.yaml and research/sdk/client.py.

## Research monthly and PAYG accounting
Standard and Pro support monthly entitlement with included units, optional prepaid overage, or PAYG with no included units and a prepaid wallet. Operator-only idempotent funding events use external payment references and exact UTC expiry supplied by the future payment integration. Renewal replaces the included allowance, preserves prepaid units and does not automatically charge a card. Balances never go negative. Pro access is checked independently of the wallet. Technical default unit costs (not euro prices): request 1, export 5, global export 20, additional 10 for each newly queued job, usage/entitlements 0. Authenticated admitted requests consume units even if application validation later fails; idempotent job retries consume only the request unit, not compute again. Cancelled jobs are not automatically refunded in this increment. Tenant and shared fixed second/minute/hour/day counters limit both requests and weighted units, with atomic debits and hard queue admission limits. HTTP 402 for insufficient balance and 429 for capacity. The cap values are provisional engineering guardrails, not capacity benchmarks. No payment processor or commercial prices configured. Existing installations require reviewed migrations; this alpha schema is for fresh installation.

## Game-to-Research dataset bridge
Migration 043 adds explicit world-level dataset approval and signed aggregate outbox. Only opted-in worlds publish supported EUR French macroeconomic observations in the final world-clock transaction. Closed numeric feature schema, HMAC world aliases, no actor IDs, raw ledgers, messages, profiles, secrets or personal records. Idempotent world/day import, bounded pages, verified HMAC. Sharing is off by default; eligibility and legitimate use must be approved before setting wp_game_dataset_consent.enabled=1. Capacity profiles are stored in shared MariaDB and configurable by the trusted operator without redeployment: `WP_RESEARCH_OPERATOR=YES php games/world-politics/research/operator.php set-capacity standard 60 60 300` (profile, seconds, maximum requests, maximum weighted units). Settings are engineering controls, not a performance guarantee; independent edge limits are still required for unauthenticated traffic. Current queue capacity is checked using a locking read. Tests exercise live profile changes and no debit on capacity denial.

## Persistent Research domestic world increment
The isolated Research database now holds signed world heads and an append-only, replayed command journal. Initialization uses the same pinned French 2027 domestic engine/configuration as the career economy. The research-only hypothetical principal has no live game or legal authority. At most 180 simulated days, 64 commands, seven days per command; 10 additional credits per simulated day, charged atomically on successful new transition. Expected revisions and idempotency keys reject stale or duplicate computation. Own state and state/action/next-state datasets (daily observations, null reward) are available via REST/SDK. Source hashes of the PHP edition and configuration are pinned; upgraded editions require retained runtime or explicit migration. The model does not yet simulate interactive constitutional/diplomatic dynamics, foreign economies or scientifically calibrated causal policy responses. Replay costs need load qualification. The shared global feed of these new transitions is not yet implemented. Fresh alpha schema only; existing DB migration must be reviewed.

The Research Pro `/datasets/transitions` feed now exposes only currently opted-in, signed persistent research transitions, with pseudonymous world IDs, manifest and numeric/model-policy data. It verifies the event and head signatures; it is not a fresh full replay of every world on each global page. Private transitions remain accessible only to their owner. Operator `withdraw-game-dataset <world_alias>` removes previously imported aggregate game rows and installs a permanent tombstone blocking old signed batch reimport. Source-world disabling and Research withdrawal must both be performed; no automated cross-database withdrawal coordinator yet. Payment event references are unique across tenants, not just within a tenant. Actual payment-provider settlement, refunds and chargebacks remain unintegrated.

## Research multi-node acceptance
The isolated extracted-source HTTP suite also starts a second PHP HTTP instance on the same MariaDB database. A ten-request concurrent burst is constrained by a four-request shared tenant daily ceiling; exactly four request units must be debited. Concurrent submission of an identical experiment on both nodes must yield the same job ID with only one compute charge and two transport charges. This is a small deterministic concurrency regression, not an infrastructure throughput or production saturation benchmark. The SDK also accepts the Pro game-world and transition dataset scopes.
