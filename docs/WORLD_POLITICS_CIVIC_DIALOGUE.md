# WP36 — fictional civic dialogue

fr-dialogue-v1 is an opt-in extension to the existing French public opinion
checkpoint. It preserves prior scenarios without changing their snapshot shape.
No new migration: the daily dialogue state and its history are nested in the
WP35 replay-verified opinion aggregate. The shared world fence and checkpoint
cover both. GET /worlds/{world}/countries/FR/dialogue exposes current fictional
dialogue only to world members. The opinion endpoint exposes its daily journal.

The two illustrative groups are a trade union and a retirees' civic association.
Independent states distinguish idle, requested consultation, open dialogue,
unresolved disagreement, and observed relief. The model records consultation
episodes and meeting counts. Prolonged fictional pressure can produce abstract
collective action; civic association participation never becomes work withdrawal.
Activity decays gradually after pressure subsides. An illustrative bounded
service-continuity index is not a prediction of real disruption, does not target
individuals, workplaces or infrastructure, and is not fed back into GDP or the
domestic ledger. No coercive tactics, legal strikes or political regime changes
are simulated by this module.

Observed relief is not a signed agreement; neither an AI nor a user can
certify legal collective bargaining via this API. The alpha does not yet expose
government negotiation decisions or the verified enactment bridge. The adverse
policy, recovery and multi-day collective action are exercised by domain tests
using a fictional enacted policy. HTTP tests exercise the durable idle state,
journal, access control and coherence. Real unions, representative mandates,
labour law, detailed service-sector data and signed agreements remain open.
